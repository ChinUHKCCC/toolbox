CryptoJS AES — Encrypt / Decrypt (browser)

This demo performs AES entirely in the browser using CryptoJS. Choose simple or advanced mode below.

Modes explained:
  • Simple mode: CryptoJS uses a passphrase-based OpenSSL-style derivation (convenient for demos).
  • Advanced mode: Derives a 256-bit key with PBKDF2, uses a random IV and includes salt+iv in the output JSON (recommended if you need better control).
Security notes: Client-side encryption is suitable for demos and some privacy use-cases but be careful for production secrets. Use strong, high-entropy passwords, and prefer Web Crypto API for production-grade implementations. Never trust code served from third-party CDNs in sensitive apps unless you vendor/serve the script yourself.
